# Ghostrunner

在 Minecraft 里还原《幽灵行者 2》！

---

## 已实现功能

### 🏃 跑酷系统
- **跑墙**——贴墙即触发，匀速沿墙奔跑，可跳出。含相机倾斜（绕视线轴翻滚 15°）、方向锁定（进入后不随视角变向）、方块黑名单（树叶、雪、藤蔓等不能跑）
- **冲刺**——WASD 方向输入（含斜向），耐力消耗（默认 4 连冲），衰减消除惯性，附带屏幕边缘暗化 + 速度线特效
- **爬墙**——面对 2~3 格高的墙按空格触发，单方向/斜向均可识别，带冷却
- **子弹时间**——空中长按冲刺键进入，附近实体实际变慢（非视觉欺骗），下落极缓，可自由瞄准方向，松开或耐力耗尽则朝目标方向冲刺

### ⚔️ 战斗系统
- **一击必杀**——被任何伤害命中即死；你的任何攻击也秒杀一切生物
- **范围挥砍**——3D 视线坐标系，AABB 最近点判定，支持"掠过斩"。平视打不到小僵尸，需**低头**或**滑铲**（预留滑铲玩法空间）
- **盾牌交互**——目标举盾面向你时挡下攻击并把你弹开；背后攻击无视盾牌。预留升级接口供未来"锋利刀刃"覆盖

### 💀 生存设定
- **溶于水**——碰到水或岩浆立刻死亡
- **无饥饿**——饱食度锁定满值，不消耗
- **无摔落伤害**——从任何高度落地无伤
- **自定义死亡界面**——红色故障滤镜、两侧滚动数据流、扫描线、"致命失误！"闪烁标题、底部按键条提示，含入场动画

### 🎨 UI
- **自定义准星**——三层六边形（白 + 亮蓝 + 淡蓝）+ 45° 刻度线，替代原版十字准星
- **耐力条**——弧形设计，白色外框 + 蓝色填充，从中央向两侧伸缩，两端金属铆钉，满耐力自动隐藏，淡入淡出
- **改造标记**——改造后隐藏原版血条和饱食度

### 🧬 幽灵行者改造
- **改造器物品**——右键打标记，施加"飞升"伤害并播放雷击音效
- **状态持久化**——NBT 存储，死亡重生 / 维度切换 / 退出重进均保留
- **快速复活**——死亡界面按 R 跳过重生按钮
- **能力门控**——未改造的玩家无法跑墙 / 冲刺 / 子弹时间

### 🔧 基础设施
- **自定义按键**——R 键快速复活（可在控制设置中修改）
- **数据包标签**——跑墙黑名单通过 JSON 配置

## 计划实现功能

- **滑铲**——配合范围挥砍的"低身位"判定，平视即可攻击矮小目标
- **裂隙干扰（抓钩）**——钩索位移
- **幽灵行者点数**——击杀敌人获取
- **芯片升级系统**——属性强化、技能树、"锋利刀刃"等
- **杰克的刀**——高精度模型 + 自定义近战动画
- **招架 / 弹反**——时机判定 + 反击机制
- **手里剑**——投掷物 + 自动索敌
- **杀招**——超级技能！
- **更多跑酷内容**——如手里剑创建钩索点位，翼装飞行等
