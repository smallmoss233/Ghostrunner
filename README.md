# Ghostrunner

在 Minecraft 里还原《幽灵行者 2》！

---

## 已实现功能

### 🏃 跑酷系统
- **跑墙**——贴墙即触发，沿进入时的锁定方向**匀速水平前进**（不受重力、不随视角变向）。含相机倾斜（绕视线轴翻滚 15°）、方块黑名单（树叶、雪、藤蔓等不可跑）
- **冲刺**——WASD 方向输入（含斜向），耐力消耗（默认 4 连冲），仅空中衰减消除惯性，附带屏幕边缘暗化 + 速度线特效
- **爬墙**——面对 2~3 格高的墙按空格触发，单方向/斜向均可识别，带冷却
- **子弹时间**——空中长按冲刺键进入，**通过 `/tick rate` 全局减速**（AI / 物理 / 粒子 / 动画同步变慢），玩家物理同样受影响但 UI 与相机保持流畅。耐力按真实时间计算（进入时冻结，释放时结算）；松开或耐力耗尽则朝瞄准方向冲刺

### ⚔️ 战斗系统
- **一击必杀（双向）**——被任何伤害命中即死（除成功格挡）；你的任何攻击也秒杀一切生物
- **范围挥砍**——3D 视线坐标系（前 / 侧 / 上三轴独立阈值），AABB 最近点判定，支持"掠过斩"。平视打不到小僵尸，需**低头**或**滑铲**（预留滑铲玩法空间）
- **盾牌交互**——目标举盾面向你时挡下攻击并把你弹开；背后攻击无视盾牌。预留升级接口供未来"锋利刀刃"覆盖
- **格挡**——右键进入，分**三阶段**（前摇 300ms → 完美窗口 300ms → 普通格挡）。普通格挡消耗 30 耐力完全抵消伤害；完美格挡近战反伤、远程耗耐力弹反。**松开右键有 400ms 硬直**——防止反复按右键刷完美窗口
- **弹反**——举剑瞬间弹开前方迎面飞来的弹射物，速度基于原速放大，附带闪光与举剑姿态。四层过滤：距离 → 前锥 → 飞行速度 → 迎面判定

### 💀 生存设定
- **溶于水**——碰到水或岩浆立刻死亡
- **无饥饿**——饱食度锁定满值，不消耗
- **无摔落伤害**——从任何高度落地无伤（包括子弹时间结束后 2 秒宽限期）
- **自定义死亡界面**——红色故障滤镜、两侧滚动数据流、扫描线、"致命失误！"闪烁标题、底部按键条提示，含入场动画；隐藏原版重生与标题屏幕按钮

### 🎨 UI
- **自定义准星**——三层六边形（白 + 亮蓝 + 淡蓝）+ 45° 刻度线，替代原版十字准星，仅第一人称显示
- **耐力条**——白色外框 + 蓝色填充，从中央向两侧伸缩，两端金属铆钉，满耐力自动隐藏，淡入淡出；格挡和子弹时间期间不恢复
- **第一人称剑持握姿态**——格挡时按阶段切换（前摇 / 完美 / 格挡），弹反瞬间剑向前刺出，姿态之间指数平滑过渡
- **改造标记**——改造后隐藏原版血条、护甲与饱食度

### 🧬 幽灵行者改造
- **改造器物品**——右键打标记，施加"飞升"伤害并播放雷击音效
- **状态持久化**——NBT 存储，死亡重生 / 维度切换 / 退出重进均保留
- **快速复活**——死亡界面按 R 跳过重生按钮
- **能力门控**——未改造的玩家无法跑墙 / 冲刺 / 子弹时间

### 🔧 基础设施
- **自定义按键**——R 键快速复活（可在控制设置中修改）
- **数据包标签**——跑墙黑名单通过 JSON 配置
- **自动注册工具**——`AutoRegister` 适配 1.21.2+ 的 `setId` 强制要求，支持 item / block / entity / blockEntity
- **网络包 API**——`PayloadRegistrar` / `ServerHandlers` / `ClientHandlers` 简化注册与接收；同类 payload 通过枚举参数合并
- **参数集中**——所有手感参数集中在 `GhostrunnerConfig`，调优无需翻代码

## 开发状态

**Beta**——核心机制已完成，手感打磨基本收敛。已从 1.20.1 迁移至 26.3，跟进原版渲染管线重构（RenderState / SubmitNodeCollector）与输入系统迁移（GLFW → SDL3）。

代码已做过一轮系统性重构：
- 状态集中到 `GhostrunnerData`，接口合并为 `GhostrunnerPlayer`
- 所有时长改用毫秒（`System.currentTimeMillis`），与 tick rate 解耦
- 网络包从 15 个合并到 7 个，注册通过 `PayloadRegistrar`
- HUD / 死亡界面 / 持剑姿态重新设计，去除每帧对象分配
